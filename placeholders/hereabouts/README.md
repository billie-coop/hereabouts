# hereabouts

This package is a placeholder. Install the maintained package instead:

```sh
npm install @billie-coop/hereabouts
```

[@billie-coop/hereabouts](https://www.npmjs.com/package/@billie-coop/hereabouts) is
internationalization for JavaScript and TypeScript, built on Unicode CLDR: numbers, decimal
math, currencies, dates and time zones, units, plurals, messages and translations.

Docs and examples: [billie-coop.github.io/hereabouts](https://billie-coop.github.io/hereabouts/).
