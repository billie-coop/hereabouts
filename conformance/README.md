# Conformance cases

Test cases shared by every implementation of hereabouts. Each line of a `.json` file is one
case: a TypeScript function name, its arguments, and what the TypeScript returned:

```json
{"fn":"decimalAdd","args":["1.5","2.25"],"result":{"data":[375],"sign":1,"exp":-2,"flag":0}}
```

Errors are recorded as `{"error": "<message>"}`. Decimal arguments are strings.

The TypeScript implementation is the reference. The cases are generated by running it over a
fixed list of inputs plus seeded random ones (`packages/hereabouts/scripts/conformance/`), so
the files change only when behavior or inputs change.

- `yarn conformance` regenerates the files.
- `yarn test` fails if a file no longer matches what the TypeScript returns. If the change in
  behavior is intended, regenerate and commit the file.
- `zig build test` (in `zig/`) runs every case against the Zig port.

| file | covers |
|---|---|
| `decimal.json` | decimal and rational math, parsing, formatting |
